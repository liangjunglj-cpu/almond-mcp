Analysis settings

Select the structure

Use member axes, shell surfaces or meshes. Include point objects for declared supports.

Required: select the structure in Rhino, then Use Rhino selection.

Section assumptions

Sections are inferred where supported. Otherwise beams use CHS 114.3 × 4 mm and shells use 100 mm thickness.

Truss assemblies use beam elements in this workspace. Axial-only member releases are not applied.

Colours show the maximum utilization mapped to each source member. Arrows show direction; lengths are symbolic. Up to 80 imposed-load symbols are shown. Self-weight acts throughout the model.

Loads

Split across free nodes. If all nodes are supported, the imposed load acts on all nodes.

Every bay enclosed by beams carries the area load (45° distribution). Residential: 2.0 imposed + about 1.0 build-up.

Add a load before running: a total load, a floor load, or self-weight.

Supports and joints

Fixed restrains translation and rotation; pinned, translation only. Simple joints pin the beam ends, as for bolted steel or timber.

Code and checks

All at their defaults

The defaults suit a first check. Change these for a National Annex profile, a stricter deflection limit, or tubes specified as hot-finished.

Load factors, material factors and the deflection limit come from the design code profile.

How the hollow sections are made. Cold-formed is the safe default; choose hot-finished only when it is specified.

          03 / ENVIRONMENT WORKSPACE

          Climate, Rooms
          & Comfort.

          Open AlmondEnvironment in Rhino to connect this workspace to your model.

          01 Site and climate

          Point Almond at an EnergyPlus weather file (.epw) for the site. It sets the sun, the sky and the outdoor air for every study.

          Required: a weather file. Typical-year files for most cities are published by climate.onebuilding.org.

          02 Rooms

          A room is a closed volume, the surfaces that bound it, or a closed curve with a height. Select it in Rhino, name it and define it. Rooms may be open, like pavilions and loggias: Almond checks each room's enclosure and says how it will be assessed.

          Set-points

          The room use sets gains, schedule and set-points. Open and semi-open rooms are never heated or cooled.

          RoomUseAreaEnclosure

            03 Constructions

            Give walls, slabs, roofs and windows a layered construction. Each room takes the construction of the elements around it; a room's construction set fills the rest.

            Sources and licences

              Layer properties come from openly licensed datasets. Finishes, frames and the assembly build-ups are Almond's assumptions: check them against product data. U-values follow the EN ISO 6946 procedure, thermal mass the EN ISO 13786 periodic method.

              Notes & warnings
                Code check

                  Method & limits

                  Thermal: each enclosed room is an ISO 13790 hourly 5R1C zone with the U-values and thermal mass of its constructions, solar gains ray traced on the model, and heat flow to neighbouring rooms. Semi-open rooms add the air that flows through their openings and run free. Open rooms are assessed as semi-outdoor comfort: outdoor air, sun and sky on the occupants (SolarCal), SET*. Daylight: daylight coefficients with interreflections, per room on a 0.8 m work plane.

                  A design-stage comparison tool. Code checks are indicative and are not certification or a compliance calculation.

                  03 / ABOUT THE ARCHIVE

                  One object.
                  A connected record.

                  Almond brings generated 3D models, architectural drawing elements, and derived linework together. A stable object ID connects every representation to its dimensions, metadata, and source evidence.

                  Built for a working practice.

                  Search by name, category, tag, or drawing role. Rotate a model, inspect available plan and elevation silhouettes, then take a GLB, SVG, DXF, or A3 sheet into your workflow.

                  Evidence stays with the object.

                  Generated GLBs embed an Almond passport. Object records include generation prompts, task identifiers, measured bounds, and known evidence gaps. Reference directories remain separate from actual generation inputs.

                  Local, and connected to MCP.

                  The archive reads the canonical Almond libraries on this computer. Saved objects stay in this browser. The MCP repository search uses the same catalogue, and drawings remain linked to their source mesh.

                  Run almond-mcp library --open to open the archive. Restart the server after adding assets to the manifests.

                  Representation has limits.

                  Generated geometry is a design aid. Derived views are projected silhouettes; they do not establish construction assemblies, product specifications, or internal and hidden edges. Drawing elements may have estimated dimensions and separate source terms.
