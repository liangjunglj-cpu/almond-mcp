02 Define the setup

Load factors, material factors and the deflection limit come from the design code profile.

Split across free nodes. If all nodes are supported, the imposed load acts on all nodes.

Every bay enclosed by beams carries the area load (45° distribution). Residential: 2.0 imposed + about 1.0 build-up.

Fixed restrains translation and rotation. Pinned restrains translation only.

Section assumptions

Sections are inferred where supported. Otherwise beams use CHS 114.3 × 4 mm and shells use 100 mm thickness.

Truss assemblies use beam elements in this workspace. Axial-only member releases are not applied.

        03 / ABOUT THE ARCHIVE

        One object.
        A connected record.

        Almond brings generated 3D models, architectural drawing elements, and derived linework together. A stable object ID connects every representation to its dimensions, metadata, and source evidence.

        Built for a working practice.

        Search by name, category, tag, or drawing role. Rotate a model, inspect available plan and elevation silhouettes, then take a GLB, SVG, DXF, or A3 sheet into your workflow.

        Evidence stays with the object.

        Generated GLBs embed an Almond passport. Object records include generation prompts, task identifiers, measured bounds, and known evidence gaps. Reference directories remain separate from actual generation inputs.

        Local, and connected to MCP.

        The archive reads the canonical Almond libraries on this computer. Saved objects stay in this browser. The MCP repository search uses the same catalogue, and drawings remain linked to their source mesh.

        Run almond-mcp library --open to open the archive. Restart the server after adding assets to the manifests.

        Representation has limits.

        Generated geometry is a design aid. Derived views are projected silhouettes; they do not establish construction assemblies, product specifications, or internal and hidden edges. Drawing elements may have estimated dimensions and separate source terms.
